HORIZON Snapshot — Template Authoring Guide

For the marketing team. How to build a Canva template the Snapshot system can fill automatically. Last updated 8 July 2026.

The golden rule. Put a named data field wherever a value, summary or map should change per property. Never type or paste content over the artwork. Named fields are what let the system fill your template cleanly and keep it pixel-perfect. Text pasted over a flattened image is what caused the old misaligned, overlapping look — we are moving away from that.

How it works, in six steps

  1. Design the page in Canva using an AgriProve brand kit.
  2. Wherever content changes per property, add a Canva data field (a text box or an image frame) and name it exactly from the cheat-sheet below.
  3. One field per frame, generously sized (frames are fixed, so leave room for longer values).
  4. For maps, add an image frame and name it (e.g. zone_map). Do not draw a legend — the system adds the correct legend.
  5. Everything else stays as static artwork and is never touched.
  6. Publish as a Brand Template. Paste the link into the Template Hub, confirm the auto-mapped fields, preview with a sample property, and publish live.

To name a field in Canva: select the text box or image frame, then rename the layer to the exact field name (Layers panel). The system reads those names.

Adding a metric that is not on the list

If a template needs a value that is not on the cheat-sheet (for example a partner metric like LawrieCo's microbe test output), name the field in a partner namespace, e.g. lawrieco.microbe_test, and flag it in the Template Hub. The PM approves it once, choosing how it is filled: manual (typed in per snapshot), computed, or from a data feed. It then works like any other field.

Send-ready checklist

  1. Every changing element is a named field, not text pasted over art.
  2. Every field name matches the cheat-sheet (or is an approved new field).
  3. Every map is an image frame with a name and no baked-in legend.
  4. Text frames are generously sized for longer values.
  5. Published as a Brand Template and previewed with a sample property.
