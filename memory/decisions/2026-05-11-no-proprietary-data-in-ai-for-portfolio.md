# Decision: No AgriProve Proprietary Data into External AI Tools for Portfolio Creation

**Date:** 2026-05-11
**Owner:** Dylan
**Status:** accepted
**Source:** Compliance assessment — AI/GenAI policy gap identified in DRAFT AUP s6 (heading mentions AI; body contains only one sentence about NDAs). Full gap analysis: `inbox/cowork/2026-05-11-policy-gaps.md`.
**Confidence:** [high] — self-imposed conservative limit given absence of organisational policy

---

## Context

AgriProve has **no AI/GenAI usage policy**. The DRAFT AUP s6 heading references "AI or online text compression/summarisation tools" but the section body is a single sentence about NDAs and privacy. No rules govern what data can be input into AI tools, which tools are approved, or how outputs should be handled.

---

## The rule

**No AgriProve proprietary data into any external AI tool for the purpose of career-portfolio creation.**

This includes:
- Client data, financial data, methodology details, system architecture, internal documents, meeting transcripts, internal communications
- Prompts that describe internal AgriProve operations — even without pasting data, describing how systems work could constitute disclosure per cl 19.3.1

**AI tools may be used for:** general writing assistance, formatting, public information research, PM methodology advice — anything where the input does not contain or describe Confidential Information.

**Output review:** All AI-generated portfolio content must be reviewed against the [9 Portfolio Rules](2026-05-11-portfolio-rules.md) before use.

---

## Rationale

This is a self-imposed rule pending organisational AI policy. Letter of Offer cl 19 (perpetual confidentiality) provides the binding coverage, but the absence of clear organisational guidance on AI usage means conservative limits are prudent. The recommendation to leadership to complete AUP s6 is noted in the policy gaps file but falls outside portfolio scope.

---

## Scope

Applies during employment. After termination, cl 19.8 (perpetual obligation) continues to govern what data can be disclosed — the AI-specific framing becomes moot but the underlying confidentiality obligation persists.
