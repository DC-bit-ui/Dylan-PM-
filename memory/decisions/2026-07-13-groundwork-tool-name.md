# Tool named "Groundwork" — top-of-funnel HORIZON Profile pipeline manager

**Date:** 2026-07-13
**Owner:** Dylan
**Status:** accepted (Dylan) — leadership alignment recommended (see note)

## Decision

The native tool being built to manage the top-of-funnel recruitment phase — intake
of report requests, HORIZON production, review/send, and engagement through to
close — is named **Groundwork**.

The document it produces is a **HORIZON Profile** (per
[`2026-07-11-snapshot-renamed-horizon-profile.md`](2026-07-11-snapshot-renamed-horizon-profile.md);
supersedes "HORIZON Snapshot").

## Rationale

- Product-line coherence: **Frontier** owns the geospatial/acquisition edge;
  **Groundwork** owns the recruitment/conversion phase that turns a prospect into a
  sent HORIZON Profile and works the deal to close. "Laying the groundwork" is
  literally what top-of-funnel recruitment is.
- Soil/land theme without clashing with the HORIZON model brand.
- Considered and set aside: Seedbed, Catchment, Homestead.
