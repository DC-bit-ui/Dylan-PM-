# Focus Skill

## Workflow

1. **Read** `workspace/current/actions.md`, `memory/initiatives/INDEX.md`, latest standup if any.
2. **Score each open item** roughly on:
   - **Urgency** — deadline, blocking others, decay window
   - **Leverage** — does Dylan uniquely need to do it, or can it wait / delegate?
   - **Strategic weight** — how much does this move a KR?
3. **Pick top 3.** Be ruthless. Anything below #3 is "later".
4. **Output**:

```
## Focus — <YYYY-MM-DD>

### Top 3
1. <item> — why: <…> — done looks like: <…>
2. <item> — why: <…> — done looks like: <…>
3. <item> — why: <…> — done looks like: <…>

### Defer (acknowledged but not today)
- <item>

### What I'd cut entirely
- <item> — because <…>
```

5. **Update** `workspace/current/actions.md` to reflect the focus, but never delete the deferred items.

## Heuristic

If Dylan finishes the day having done all 3, that's a good day. More than 3 = thrash.
