# workspace/current/

> What Dylan is actively working on **this week**. The `focus` and `daily-standup` skills read from here. The `initiative-tracker` reconciles items here against `memory/initiatives/`.

## What lives here
- `actions.md` — running list of open commitments with owner + due date
- `standup-YYYY-MM-DD.md` — daily standup entries (rotate weekly)
- `focus-YYYY-MM-DD.md` — daily top-3 picks (optional save)
- `<scratch-doc>.md` — anything in flight that's not yet a deliverable

## Rules
- Things that are **done** move to `workspace/archive/` or get filed into `memory/deliverables/` if they're artifacts worth keeping.
- Don't keep things in `current/` more than 2 weeks. Either ship them, escalate them, or move them to an initiative file.
